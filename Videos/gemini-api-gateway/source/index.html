05 / BOUNDARY

能做什么，不能做什么

DO

  • ✓只使用自己或组织已授权的项目与 Key
  • ✓客户端只拿虚拟 Key，上游 Key 留在服务端
  • ✓设置限流、预算、模型白名单与日志脱敏
  • ✓管理后台放内网、VPN 或 SSO 之后

DON'T

  • ×批量注册账号或项目来绕开额度限制
  • ×公开分享 Key、网关地址或管理后台
  • ×把数据库、管理面直接暴露到公网
  • ×未授权转售或对外提供 API 额度
网关不提升额度。先确认授权，再谈接入。
