## 约定

- 一个交付物一个 `.html` 组，CSS/JS 与图片全部内联，不依赖 CDN、网络或本地服务器。
- 页面之间只用链接导航，保证单文件可独立打开。
- 事实、原文引用与推断分开标注；文末写清来源与许可；数据类页面注明抓取时间。
- 摘录型内容保留原文，不做 AI 改写；缺失的地方如实标注。
- 自动归类（关键词、规则）要在页面上写明方法与边界，不当作人工精标。
