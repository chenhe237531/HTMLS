30 秒读懂

AttnRes 是标准残差连接的替代品：每层用一个可学习的 pseudo-query，对之前所有层的输出做 softmax 注意力，从而按输入内容选择性聚合历史表示。Block AttnRes 把层分块，把显存从 O(Ld) 降到 O(Nd)，约 8 块就能接近 Full 版本。

  • 解决 PreNorm 下隐藏状态随深度无限增长、各层贡献被稀释的问题。
  • Full AttnRes：每层 attend 所有历史层输出；Block AttnRes：块内普通残差、块间注意力。
  • 在 Kimi Linear 48B/3B、1.4T token 上验证：GPQA-Diamond +7.5，HumanEval +3.1。
  • 官方称 Block AttnRes 约等于多 1.25× 计算量的基线。
01

机制

标准 Transformer 的残差是 h_l = h_{l-1} + f(h_{l-1})，所有历史层以固定权重 1 累加。AttnRes 改成 h_l = Σ α_{i→l} · v_i，其中 α 由每层一个可学习向量 w_l 对历史层输出做 softmax 得到。这样每层可以“回看”并选择它需要的表示，而不是被动接收累加结果。

Full 版本要为每层保留所有历史输出，显存 O(Ld)。Block 版本把层分成 N 块，块内继续用普通残差，只在块级表示之间做注意力，显存降到 O(Nd)；官方实验显示 8 块左右即可恢复大部分收益。

02

证据与边界

README 给出 scaling law：AttnRes 在所有计算预算下优于基线，Block 版本匹配“多 1.25× 计算量”的基线。下游任务上，GPQA-Diamond 从 36.9 到 44.4，HumanEval 从 59.1 到 62.2，C-Eval 从 79.6 到 82.5。

仓库是论文配套的 PyTorch 伪代码与结果，不是一个可直接 pip 安装的库。要用它必须改模型结构并重新训练；“drop-in replacement”指的是结构上可替换，不是推理期插件。
