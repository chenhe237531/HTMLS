30 秒读懂

MoonPalace 是 Moonshot AI 提供的 API 调试代理：启动后把代码里的 base_url 换成 http://localhost:9988，它就会捕获完整请求，包括网络错误时的现场；支持按 request_id / chatcmpl_id 检索、按 predicate 筛选、一键导出 BadCase。

  • 全平台：macOS、Windows、Linux。
  • 捕获完整请求体，网络错误也能留下现场。
  • 按 request_id、chatcmpl_id 快速检索。
  • 导出结构化 BadCase，方便反馈给 Moonshot 改进模型。
01

解决什么调试痛点

调 API 时最常见的问题是“模型输出不符合预期，但不知道请求到底发了什么”。MoonPalace 作为本地代理，把每次请求完整落盘，并提供自动缓存、内容截断检测、重复内容输出检测。你可以按 id 找回某次请求，也可以按条件筛出一批相似请求。

02

使用方式

用 go install github.com/MoonshotAI/moonpalace@latest 安装，或从 Releases 下载二进制；启动后改 base_url 即可。配置文件 config.yaml 可调缓存与检测行为；导出命令支持 id / chatcmpl / requestid 任选其一。
