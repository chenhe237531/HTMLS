x402 的代币地图

x402 协议本身没有代币，也没有协议费。围绕它的 Web3 价值，分布在稳定币、结算链、facilitator 与 Agent 平台四层。看清「谁收费、谁必需代币」，比看概念板块更重要。

01

先看结论

x402 是一个开放支付标准，不是代币项目。它的治理在 Linux Foundation 下的 x402 Foundation，协议本身不收协议费。因此，绝大多数「x402 代币」并不是协议代币，而是围绕支付流量做生意的项目代币。

协议层

x402 Foundation 无代币；Coinbase、Cloudflare 是公司，只有股权（COIN、NET），没有协议币。

结算层

USDC 是主要结算资产；SOL、MON、XLM、XRP 等承担 gas 与安全，代币是链的必需品。

服务层

PayAI、Heurist、Meridian、Dexter 等 facilitator 有代币，但收费通常用 USDC 或 credits。

最容易被误导的地方 交易所的「x402 生态」板块会把「沾边」项目都放进去。判断标准只有一个：它的收入是否来自 x402 支付流量，代币是否捕获这部分收入？ 两者缺一，就只是概念关联。

读法 越靠近「支付本身」，代币越像货币（USDC）；越靠近「服务」，代币越像股权替代品（费用、质押、返现）；越靠近「协议」，越可能没有代币。

05

价值捕获

把「谁付钱、付给谁、代币是否参与」拆开，就能看出哪些代币有真实支撑，哪些只是叙事。

层谁付钱收入规模代币是否必需代币捕获方式
协议没人（0 协议费）0否无
结算资产付款方与支付量等比是（资产本身）储备利息 + 发行
结算链付款方 / facilitator单笔极小，量大是（gas）手续费 + 质押
Facilitator商户$0.001/笔量级通常否费用、质押、返现、治理
Agent 平台开发者 / 用户平台费看设计发行、交易、分成

算一笔账

假设某 facilitator 每天结算 100 万笔、每笔收 $0.001：日收入 $1,000，年收入约 $36.5 万。若其代币完全稀释估值是 5000 万美元，市销率约 137 倍。这个量级的收入，很难支撑「支付赛道的千倍叙事」。

费用战已经开始 Dexter 等 facilitator 直接免 facilitator 费；Coinbase 每月前 1,000 笔免费；PayAI 有免费额度。费用被压到接近零时，代币只能靠质押、返现或生态准入来制造需求。

四种代币模型

费用型

协议费/服务费进国库或分给质押者。最扎实，但前提是真有收入和分配机制。

返现型

Meridian 用 MRDN 返现，制造使用激励；本质是补贴，需看排放与减半曲线。

质押型

Heurist 50% APR + 收入分成，靠通胀吸引锁定；高 APR 往往意味着高稀释。

准入/治理型

PayAI 的 Token Gateway、平台治理；需求取决于生态是否真的需要持仓。

风险与识别

风险为什么怎么识别
概念关联「x402 生态」榜单把沾边项目都收进来问：收入是否来自 x402？占比多少？
代币不必要facilitator 费用用 USDC 支付，代币可被绕过看代币是否是使用服务的必要条件
费用压缩免费 facilitator 与 $0.001 定价看单笔收入与年收入，而非交易笔数
高排放50% APR、返现减半机制看年化排放 / 流通市值
低流通高 FDV解锁带来持续卖压看解锁表与流通比例
数据不可验证交易量可能自报或刷量用链上浏览器与独立统计交叉验证
监管稳定币、证券属性、跨境支付看牌照、储备审计、司法辖区
集中度多数结算集中在少数 facilitator看市场分布与单点依赖
一句话 如果一条链上找不到「这个代币因为 x402 收入而被回购/分配/销毁」的证据，它大概率只是「x402 概念」。概念可以交易，但不能当基本面。

08

趋势

1 · 协议与代币继续分离

x402 无币、零费、基金会治理。未来更可能出现「支付标准无币、周边服务有币」的稳定结构。

2 · 稳定币拿走最大价值

USDC 的储备收益与发行规模，远大于 facilitator 的每笔费用。支付越普及，稳定币越发受益。

3 · Facilitator 费用趋零

免费与补贴会持续，代币模型转向质押、返现、准入与增值服务。

4 · 链方补贴支付流量

Solana、Monad、Stellar 等用低费与激励争夺 Agent 支付，链代币捕获 gas 与质押。

5 · 返现与积分化

Meridian 的 MRDN 返现是一种「用代币买增长」；可持续性取决于真实留存，而非补贴。

6 · 监管决定上限

稳定币立法、证券认定与跨境合规，会决定哪些项目能服务企业客户。

判断 短期看，x402 更像「稳定币 + 链」的采用故事，而不是「新代币」的故事。Facilitator 代币的机会在细分服务与真实收入，不在「协议币」叙事。
