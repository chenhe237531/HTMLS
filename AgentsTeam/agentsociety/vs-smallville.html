AgentSociety vs
斯坦福小镇

它们同源：都用 LLM 驱动 agent，都关心“涌现”。但一个想证明 25 个人能活得像人，另一个想回答 1 万个 agent 组成的社会，政策打下去会怎样。

Generative Agents · UIST 2023 AgentSociety · 2025 / 2026 不是升级关系

01一句话说清

小镇验证“个体可信”，AgentSociety 验证“群体可算”。前者是一次行为学演示，后者是一台社会科学实验装置。把后者说成“小镇的升级版”，会同时误解两边的设计取舍。

02两个命题

STANFORD · SMALLVILLE

25 个 agent，2 天

Park 等人 2023 年的《Generative Agents》。在一个 2D 小镇里放 25 个居民，每个有记忆流、会反思、会做计划，看他们能不能自发产生可信的社交行为。

最著名的结果是情人节派对：一个 agent 发起，消息在镇上扩散，其他人自己决定赴约。

问题：LLM agent 的行为，看起来像人吗？
TSINGHUA · AGENTSOCIETY

10,000+ 个 agent，500 万次交互

把 agent 放进有交通、经济、公共资源的城市，用社会学理论给它们情绪、需求、动机与认知，再施加政策或信息干预，观察群体层面的模式。

论文用五个议题检验它：极化、煽动信息、UBI、飓风、城市可持续性。

问题：一个社会在干预下会怎么演化？

04架构上的分岔

左边是“认知循环驱动一个人”，右边是“调度器驱动一座城市”。共同点是都用 LLM，差别在于把复杂度放在哪一层。

读法：小镇把复杂度放在“单个 agent 的认知循环”，环境只是布景；AgentSociety 把复杂度放在“环境 + 调度”，个体反而被压成可组合的 Block。这是两条不同的工程路线，不是同一张图的放大版。

05三个深层原因

1. 验证标准不同，架构就必须不同

小镇要回答“像不像人”，最有效的验证是让真人来读、来评、来互动；所以它优化的是单个 agent 的表达质量与记忆连贯性。AgentSociety 要回答“结论对不对”，最有效的验证是统计量与真实研究对齐；所以它优化的是采样量、可重复性与干预可控性。前者的最优解是深，后者的最优解是广。

2. 环境从“布景”变成“约束”

小镇的地图只需要让 agent 有地方可去；AgentSociety 的环境会反过来约束行为：上班要通勤、消费要看余额、灾害会断路。只有环境有独立状态，“如果所有人都改乘地铁”“如果这条路封了”这类反事实才成立。这也是为什么它要把环境做成 gRPC 服务，而不是一个二维数组。

3. 干预从“副作用”变成“实验接口”

在小镇里，你能做的最强干预是走进去和居民说话；在 AgentSociety 里，发一笔钱、推一条谣言、屏蔽一类信息，都是消息层与环境层的正式接口。社会科学实验的核心是控制变量，没有干预接口，就只剩观察。

06怎么选

按问题选，不要按“哪个更新”选。

IF 你的问题是

“agent 的行为可信吗？”

研究人机交互、角色扮演、记忆与人格一致性，或做教学演示。25 个 agent 足够，成本低，结果好读。

选小镇
IF 你的问题是

“一项政策会带来什么？”

需要对照组、需要统计、需要干预接口，还要能重放。规模是方法的一部分，不是炫技。

选 AgentSociety
IF 你的问题是

“我想改造其中一个”

改认知循环、做新的人格机制 → 小镇代码更小更好读；改城市环境、做分布式调度 → AgentSociety 的 v1 引擎更完整。

看你要改哪一层
IF 你的问题是

“我两个都想要”

现实做法：用小镇式的深度认知做个体，用 AgentSociety 式的环境与调度做群体。两者在“记忆 + 反思 + 计划”这一层是共通的。

组合，而非二选一

07三个常见误读

MISREAD 01“AgentSociety 就是放大版的小镇。”
规模不是唯一变量。放大 400 倍之后，记忆流式的全量上下文跑不动，必须换成 Block 组合 + 环境服务 + 异步调度；认知架构整个换了。
MISREAD 02“小镇已经过时了。”
它的命题（个体可信度）至今没有被取代。做角色一致性、记忆机制、人机共处，25 个 agent 的沙盒仍然是更合适的实验床。
MISREAD 03“AgentSociety 能预测真实社会。”
论文的措辞是复现主要定性模式、识别有信息量的偏离。它是假设生成器与实验台，不是预言机；输入分布一变，结论就不可迁移。
