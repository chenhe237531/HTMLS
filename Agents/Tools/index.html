03

怎么选

只想在终端里改代码

先试 OpenCode；想要极小核心、自己拼扩展，选 Pi。要后台自治、把任务丢进沙箱，再叠加 OpenHands。

同时跑多个 agent

用 Orca：每个任务独立 worktree，终端/浏览器/diff 审阅在一个窗口，远程和手机接管是它的差异点。

要一个常驻个人助手

Hermes：消息网关、记忆、技能、cron 都在一个运行时里。偏 MCP 工具编排和桌面/CLI 双形态，选 Goose。

要把任务丢进沙箱后台跑

OpenHands：Agent Canvas 看过程，Docker/远程沙箱执行，SDK/Server 可嵌入内部平台。

04

未纳入与变化提示

  • OpenClaw（MIT）：聊天渠道、持久记忆、技能与 Hermes 高度重叠；除非需要它的 29 个渠道和移动节点，否则先不装。
  • Clippy：同名项目较多（cellwebb/clippy-code、AISocratic/clippy、Clippinator 等），未确认你安装的具体仓库，暂不单列；给出 repo 链接可补一篇。
  • Continue：公开仓库在 2.0.0 后转为只读，不建议作为新装选型。
  • SWE-agent：偏 benchmark/研究复现，不适合日常开发。
