01先回答你的问题

字节：没有叫 “Skills Hub” 的公开产品

和 Skills 最接近的是扣子（Coze）的技能商店：2026 年 1 月起，扣子 2.0 把 Skill 做成可发布、可调用、可分成交易的商品，入口在扣子空间内，主打“一句话生成技能”。另外「剪映 Hub」是同名但不同物——那是视频创作工作台，不是技能仓库。

美团：有，但分两层
  • 对外：developer.meituan.com 的 AI Hub，已上架酒旅 Skill、AI Coding Skill 等，支持 MCP / Skill / CLI 一体化接入，个人开发者实名后即可拿 Token 使用。
  • 对内：2026 年 3 月的美团招聘 JD 明确写到“开发和运营 Skill Hub 平台，支持 Skill 的发布、发现、搜索、评分、版本管理与权限控制”，以及 Skill 社区生态。这是内部基础设施，没有公开站点。

判断标准：一个“Hub”至少要同时具备 发布 / 发现 / 版本 三件事。只有仓库没有检索，是 library；只有列表没有托管，是 awesome list；两者都不是市场。

03四类形态，别混着用

形态它解决什么典型你要额外做的判断
官方市场 托管、版本、分发、有时带交易 ClawHub、扣子技能商店、美团 AI Hub 是否绑定单一 agent？能否导出成标准 SKILL.md？
独立目录 跨平台检索、比较、打分、审计 skills.sh、Agent Skills Hub、SkillHub、SkillRepo 评分口径是什么？数据多久没更新？谁付的钱？
代码仓库 可审计的源文件、可 fork、可自托管 anthropics/skills、Futu Agent Hub、mcode-stack 有没有维护者、许可证、更新节奏？
CLI / 协议 把“安装”统一成一条命令 skills CLI、clawhub CLI 装到哪个目录？能不能锁定版本、能不能卸载干净？

04装之前查六件事

  • 来源可追溯：能点回源仓库，能看到 commit 或 digest，而不是只有一张介绍页。
  • 权限写清楚：会读哪些目录、发哪些网络请求、要不要 token；没有说明的一律当高权限。
  • 版本与锁：有 semver 或 lockfile，能回滚；只有 latest 的不要进团队流程。
  • 评分口径：区分“安装量”“人工评级”“自动扫描”，三者不能互相替代。
  • 数据新鲜度：目录页上的扫描日期超过三个月，就要按未审计处理。
  • 可卸载：装进去的东西能干净删掉，且不会静默改你的 AGENTS.md。
一句话原则

Hub 负责“找到”，不负责“担保”。任何目录的 A 级评级，都只是让你少看几个仓库，不是允许跳过读 SKILL.md。
